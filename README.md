# 인천항 선사 스케줄 vs 터미널 접안 스케줄 비교

수입팀에서 선사별로 공지하는 선박 스케줄과, 실제 터미널 접안(예정) 스케줄이
서로 어긋나는 문제를 해결하기 위한 프로젝트입니다. 선사 사이트의 스케줄보다
터미널의 실제 접안 스케줄이 더 정확하다는 전제 하에, 선박별로 두 스케줄을
나란히 비교할 수 있게 합니다.

## 구성

- [scrapers/icon_terminal.py](scrapers/icon_terminal.py): 인천항만공사(IPA)가 운영하는
  [iCON 통합정보](https://scon.icpa.or.kr/main.do?menuKey=19) "선석배정현황(텍스트)"을
  스크래핑합니다. 로그인 없이 인천 5개 터미널(선광/SNCT, 한진/HJIT, E1CT, 인천/ICT,
  국제여객부두) 전체의 접안(예정)일시·출항(예정)일시·선사명을 한 번에 가져옵니다.
  이 데이터가 "터미널 접안 스케줄" 쪽 기준 데이터입니다.
- [db.py](db.py): SQLite 저장소 (`schedule.db`, git에는 포함 안 됨).
- [match.py](match.py): 선박명 기준으로 터미널 데이터와 선사 공지 데이터를 매칭하고
  ETA 차이를 계산합니다. 차이가 6시간 이상이면 화면에서 강조됩니다.
- [app.py](app.py): Flask 대시보드. `/`에서 비교 표를 보여주고, "지금 새로고침" 버튼으로
  iCON을 다시 스크래핑합니다.
- [scrapers/carriers/base.py](scrapers/carriers/base.py): 선사별 스크래퍼가 구현해야 하는
  공통 인터페이스. **아직 실제로 구현된 선사 스크래퍼는 없습니다.** 인천을 드나드는 각 선사
  (CK Line, SITC, 흥아라인 등)가 자체 E-service를 운영하지만 사이트 구조가 제각각이고
  대부분 JS 기반이라, 선사별로 개별 스크래퍼를 하나씩 만들어야 합니다.
- 그동안의 임시 대안으로, 대시보드에 선박별 "수동 입력" 칸을 두어 담당자가 선사 사이트에서
  직접 확인한 ETA를 입력해두면 바로 비교에 반영됩니다 (`source=MANUAL`로 표시됨).

## 실행 방법

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 http://localhost:5000 접속. 이 PC에는 아직 Python 실행 환경이 설치되어
있지 않아, 로컬에서 직접 검증되지는 않은 상태입니다 (설치 후 안내에 따라 확인 예정).

## 다음 단계

1. 실행 환경(Python) 준비 후 전체 동작 검증 (`icon_terminal.py` 단독 실행 → `app.py` 웹앱)
2. 선사별 스크래퍼 추가 (인천 기항 빈도가 높은 선사부터: CK-LINE, SITC, 흥아라인 등)
3. 주기적 자동 새로고침(스케줄러) 추가
