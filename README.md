# 인천항 선사 스케줄 vs 터미널 접안 스케줄 비교

수입팀에서 선사별로 공지하는 선박 스케줄과, 실제 터미널 접안(예정) 스케줄이
서로 어긋나는 문제를 해결하기 위한 프로젝트입니다. 선사 사이트의 스케줄보다
터미널의 실제 접안 스케줄이 더 정확하다는 전제 하에, 선박별로 두 스케줄을
나란히 비교할 수 있게 합니다.

## 현재 상태

- [scrapers/icon_terminal.py](scrapers/icon_terminal.py): 인천항만공사(IPA)가 운영하는
  [iCON 통합정보](https://scon.icpa.or.kr/main.do?menuKey=19) "선석배정현황(텍스트)"을
  스크래핑합니다. 로그인 없이 인천 5개 터미널(선광/SNCT, 한진/HJIT, E1CT, 인천/ICT,
  국제여객부두) 전체의 접안(예정)일시·출항(예정)일시·선사명을 한 번에 가져옵니다.
  이 데이터가 "터미널 접안 스케줄" 쪽 기준 데이터입니다.
- 선사(공지) 스케줄 스크래퍼는 아직 구현되지 않았습니다. 인천을 드나드는 각 선사
  (CK Line, SITC, 흥아라인 등)가 자체 E-service를 운영하지만 사이트 구조가 제각각이라
  선사별로 개별 스크래퍼가 필요합니다.
- 비교 대시보드(웹앱)는 아직 없습니다.

## 실행 방법

```bash
pip install -r requirements.txt
python scrapers/icon_terminal.py
```

이 PC에는 아직 Python 실행 환경이 설치되어 있지 않아, 위 스크립트는 작성만 되어
있고 로컬에서 직접 검증되지는 않은 상태입니다.
